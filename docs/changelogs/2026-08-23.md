# Calliope changelog — 23 August 2026

Notes for GitHub. Version on `main` before this follow-up was **1.2.0** (`a1e329c`).

---

## 1.2.0 (on `main`)

### Agents

- New **Agents** chat: plugin harness, event-sourced session log, sandbox vs linked-project modes.
- Tools for story, script, assets, video enqueue, `run_workflow`, and workspace bootstrap (`create_project` / `link_project` / `list_projects`).
- Settings → Agent: operator **hardening rules** appended to the system prompt (blank disables). Step budget `agent_max_steps`.
- `@workflow` mentions and file attachments in the composer.
- Human-in-the-loop for renders: `enqueue_asset_jobs` / `enqueue_video_jobs` / `run_workflow` need an explicit generate/confirm.
- Comfy MCP `comfy_*` generate tools are **not loaded**. Agents use Calliope HTTP tools only (`comfy_server_info`, `run_workflow`, enqueue).
- Sandbox `@generate` queues on hidden **Playground scratch** — does not `create_project` just to make an image.
- `attach_asset`: file a finished generate (`job_id` or path) onto a film as a character sheet, environment, or misc. item. Works from sandbox; refuses Playground scratch.
- Sandbox job cards poll Playground jobs so completed images show in chat.
- Composer `@` typeahead no longer crashes (`MENTION_LIMIT`); session load shows an error / loading state instead of an empty welcome.

### Assets

- Third entity type: **Misc. Items** (props/objects). LLM-extracted, editable in Story, generated on Assets. Items do not feed video ref slots.

### Video / ComfyUI

- Role tags: `(Input:video)`, `(Input:audio)`, `(Input:clipindex)` plus existing prompt/ref/size roles.
- **H3 Motion Context**: import FirstMotion + NextMotion pair; Video toggle **Continue motion from previous clip**; per-project latent prefix so projects do not collide in Comfy’s output folder.
- Ordered generic `(Input:image)` ref slots (node-id order) for multi-ref workflows (MiniMax H3).
- Worker uploads video via Comfy `/upload/image`; duration bump when continuing motion.
- Settings → Queue: poll timeout default **30 min** (`0` = wait indefinitely). Agent `wait_for_jobs` uses the same value.

### Script / continuity

- Per-scene **Chain from prev clip** (Script tab, merged from `#15`): at job run time, take the previous scene’s last frame (ffmpeg) and swap it into the location/ref slot for continuity. Missing previous clip falls back to the scene’s own refs.

### App / install

- Windows zip install path documented for **1.2.0**.
- Example MiniMax H3 Turbo T2V / I2V API-format workflows.

### UI polish (same day, on `main`)

- Agents welcome chips stay on a newly created session (`b587c56`).

## Follow-up (this commit)

### Video — reference picker

- Project → Video: Ref tiles open a **tabbed modal** instead of a long dropdown.
- Tabs: Characters, Environments, Misc. Items, Uploads (clips + uploads when the slot is video).
- Thumbnail grid, search, Upload new…, Clear slot.
- Video picker now includes **item** images as well as sheets, environments, clips, and uploads.

### Agents — HITL tightening

- Render tools (`run_workflow`, enqueue) are **hidden** from the model until the user asks to generate or confirms. Tagging `@workflow` alone is not permission.
- `[Calliope context]` appendix is stripped before intent checks (`kind=image` in the appendix cannot unlock renders).
- Confirmation / render-intent helpers live in `harness/policy.py`.

### Misc. Items

- Generate jobs write the output path onto the **item** row (`reference_image_path`). Queue labels show `Name · item`.
- Playground **Add to project** can create a **new** misc. item (does not overwrite existing items).

## Suggested GitHub release blurb (1.2.0 + follow-up)

Calliope 1.2.0 adds Agents chat (sandbox generates without creating a film, then `attach_asset` to file the picture), Misc. Items, H3 motion-context clip chaining, video/audio ref roles, a 30-minute Comfy poll timeout, and Script-tab chain-from-previous-clip.

Follow-up: tabbed video ref picker, stricter render HITL, and item generate/attach.
